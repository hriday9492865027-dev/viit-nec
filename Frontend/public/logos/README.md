# Logo Placement Directory

Place your official logo images in this folder:
- `ecell-logo.png` -> Official E-Cell Logo (displayed Top Left)
- `viit-logo.png` -> Official VIIT Logo (displayed Top Center)
- `nec-logo.png` -> Official NEC College Logo (displayed Top Right with curved edges)

The site will automatically load these files if present, or display styled SVG badges as fallback placeholders.
